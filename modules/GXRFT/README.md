# GXRFT Module

The VRCFaceTrackingGO module for [gxr-root-ft](https://github.com/compdoge/gxr-root-ft), which streams the face and eye tracking of a rooted Samsung Galaxy XR. It is a Go implementation of [VRCFT-ALVR-UE](https://github.com/compdoge/VRCFT-ALVR-UE), whose packet format gxr-root-ft uses.
